# S.L. Dzbenski — author website

## Publishing on GitHub Pages
1. Open the `sdzbenski.github.io` repository on GitHub.
2. Choose **Add file → Upload files** and upload `index.html`, `styles.css`, and the entire `assets` folder (or drag the folder contents into GitHub’s upload area, preserving `assets/` paths).
3. Commit changes. In **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
4. Visit `https://sdzbenski.github.io` after deployment completes.

## IMPORTANT: Before sharing or submitting to Goodreads
- The Contact section now publicly displays `author.sldzbenski@gmail.com` for author correspondence and Goodreads verification.
- The website links directly to your Amazon Author Page: https://www.amazon.com/stores/S.-L.-Dzbenski/author/B0FTT7FWGP. Individual book links still lead to Amazon **search results** until you provide the specific book listing URLs.
- The About the Author section uses the author-provided biography. Review the book descriptions before sharing.
- The site uses Google Fonts; if fonts are blocked, it falls back to standard system fonts.

All five cover images supplied by the author are included in `assets/` as optimized WebP files.
